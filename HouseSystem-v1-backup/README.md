# “好房子”三维可视化系统

计算机图形学课程大作业二。基于 WebGL（Three.js）实现的住宅三维可视化系统，围绕“安全、舒适、绿色、智慧”四类特征，展示一栋单层住宅的建筑、家具、设备、人员活动和运行数据。

## 一、运行方法

### 1. 直接运行（推荐，用于演示）

用 Chrome 或 Edge 浏览器打开 `release/好房子三维可视化系统.html`（双击即可）。

这个文件已经包含全部代码、模型和贴图，不需要联网，也不需要安装任何软件。首次打开需要几秒钟加载（进度条走完即可）。

### 2. 从源代码编译

需要 Node.js 18 或更高版本。

```bash
npm install          # 安装依赖（three、echarts、vite）
npm run dev          # 开发模式，浏览器打开 http://127.0.0.1:5188/
npm run build        # 编译，生成 dist/index.html（单个文件）
bash scripts/package.sh   # 编译并复制到 release/，同时打包源代码
```

## 二、界面与操作

| 区域 | 说明 |
|---|---|
| 顶部标签页 | 总览、安全耐久、健康舒适、绿色低碳、智慧便捷、分层查看 |
| 左侧面板 | 当前功能页的按钮、开关、数据卡片和图表 |
| 右侧信息卡片 | 点击场景中的物体后显示名称、功能、状态、维护信息，设备可直接控制 |
| 左下角 | 预设视点（鸟瞰、俯视、入户、客厅、厨房、卧室、老人房、屋顶）和第一人称漫游 |
| 底部时间栏 | 时间、播放速度、日期（夏至 / 春分 / 秋分 / 冬至）、天气（晴 / 多云 / 雨） |
| 右上角 | 实时帧率和平均帧率 |

鼠标操作：左键拖动旋转，右键拖动平移，滚轮缩放，单击选择物体，双击将镜头对准物体。

漫游模式：W/A/S/D 或方向键移动，鼠标拖动转向，Q/E 转身，Shift 加速，Esc 退出。人会被墙和家具挡住。

显卡较弱、帧率偏低时，可在“总览 → 显示”中关闭“高画质”。

## 三、功能与评分要求对照

### 基础要求

| 检查项 | 实现情况 |
|---|---|
| 场景范围 | 住宅主体（地基、墙体、门窗、屋顶、女儿墙、雨棚）；8 个室内空间的家具布置；室外草坪、道路、围栏、树木、露台、花坛、路灯、电线杆、远山 |
| 模型构成 | 建筑构件、家具、家电、智能设备、消防设施、光伏与储能设备、人物、植物等十余类独立物体；墙体按门窗洞口自动切分，无重叠闪烁 |
| 尺度与空间关系 | 全部使用真实米制尺寸：层高 3m、门宽 0.9~1.0m、床长 2m、人物身高约 1.66m |
| 摄像机与视角 | 轨道旋转 / 缩放 / 平移；8 个预设视点平滑飞行；第一人称漫游（带碰撞）；双击聚焦 |
| 基础交互 | 射线拾取选择物体，信息卡片可开关、调节设备；时间、日期、天气、剖切高度等参数控制 |
| 材质与纹理 | 15 种程序化纹理（木地板、瓷砖、石材外墙、草地、布艺、大理石、光伏板等），按真实尺寸计算 UV，无拉伸错位；PBR 材质 |
| 光照与阴影 | 太阳平行光（主光，按经纬度与时间计算方向）+ 半球光（环境光）+ 天空环境贴图 + 室内点光源；PCF 软阴影 |
| 环境表现 | 基于大气散射的程序化天空盒，随太阳位置变化；草地、道路、远山、雾效；雨天粒子 |
| 视觉一致性 | 统一 PBR 材质与 ACES 色调映射 |
| 实时性能与稳定性 | 测试机约 60 FPS；重复物体使用实例化渲染；可切换画质 |
| 工程规范 | 单文件即可运行；源代码可重新编译；附自动演示截图与交互测试脚本 |

### 进阶要求

| 类别 | 实现内容 |
|---|---|
| 安全 | 厨房火灾：烟雾扩散 → 感烟探测器报警 → 声光报警、切断燃气、开门解锁、应急照明 → 防火门关闭 → A* 计算绕开火源的疏散路线，居民跑向安全出口并统计疏散用时；老人房 / 卫生间一键呼叫；安全巡检与状态视图（绿 / 黄 / 红） |
| 舒适 | 日照与阴影随时间变化；各房间日照时长射线分析（有无外遮阳对比）；自然通风与新风粒子流线；三种通风方案对比曲线；温度 / 湿度 / PM2.5 / CO₂ / 噪声热力图；轮椅无障碍路线检查 |
| 绿色 | 光伏发电功率模型（入射角、天气）；能量流动管线（光伏、储能、家庭用电、电网）；储能充放电；24 小时发电用电曲线；普通方案与绿色方案全年对比；节能模式 |
| 智慧 | 回家 / 离家 / 睡眠 / 观影 / 自动感应五种场景模式；人体感应照明、走廊灯随人移动依次点亮；设备列表与控制；燃气泄漏联动；雾霾空气质量联动；数字孪生运维（建筑透明化、故障自动定位、派单维修） |
| 交互与状态可视化 | 颜色（状态灯、状态标记、热力图）、动画（粒子、流动管线、门窗窗帘）、数值（数据卡片、场景标签）、图表（ECharts 折线图、柱状图） |
| 人物建模 | 真人角色模型（Michelle），骨骼动画；行走、跑步、站立动画通过自己实现的动画重定向从另一套骨骼动画转换而来 |

## 五、素材来源

- 人物模型 `Michelle.glb` 与动画来源 `Soldier.glb` 来自 Three.js 官方示例（原始角色与动画出自 Adobe Mixamo）。系统中只显示 Michelle，`Soldier.glb` 仅用于提供行走、跑步、站立动画。
- 餐椅、马桶、花盆的 OBJ 模型由 `tools/make-obj.mjs` 生成。
- 所有纹理由代码绘制（`src/scene/textures.js`），未使用外部图片。
- 第三方库：Three.js（MIT）、ECharts（Apache-2.0）、Vite（MIT）。

## 六、说明

- 室内环境、光伏发电、能耗、碳排放等数据为按简化模型计算的模拟值，用于展示可视化效果，不代表真实测量结果。
- 系统在 Chrome / Edge 最新版中测试通过。
